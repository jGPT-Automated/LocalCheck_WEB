# LocalCheck Web

LocalCheck is a dark, map-first court explorer for basketball and pickleball.
This MVP ships a source-backed launch catalog of 56 courts across New York
City, Washington DC, Miami, Los Angeles, Houston, Austin, and Denver.

## What is included

- Responsive Mapbox court explorer with sport, city, and text filters
- Compact cultural/venue names plus canonical official names
- Basketball and pickleball cards with distinct court geometry
- Court detail pages with check-in, local-court state, and weekly planning UI
- Supabase schema, RLS policy, public stats view, and idempotent seed
- Review workbook and source/provenance fields for every launch court

Public activity counts are omitted until test-data isolation is deployed. Player information and account actions remain in the app. Court-loading failures are explicitly unavailable, never a bundled catalog or synthetic zero.

## Run locally

Requires Node.js `>=22.13.0`.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Set these values in `.env.local`:

- `MAPBOX_ACCESS_TOKEN`
- `SUPABASE_URL`
- `SUPABASE_PUBLISHABLE_KEY`

## Court data

- `public.courts_with_stats` in the app’s production Supabase project is the website’s runtime source. The historical JSON/CSV/seed files are not a runtime fallback; do not reseed from this website.
- `data/launch-courts.csv` is the flat review/export format.
- `docs/data/localcheck-launch-courts.xlsx` is the styled review workbook.
- `docs/COURT_DATA_STANDARD.md` defines the naming and provenance rules.
- `supabase/migrations/` contains the catalog schema and RLS setup.
- `supabase/seed.sql` is generated by `npm run data:seed` and can be rerun.

The public label is never a detector number. `name` stores the canonical venue
identity, `short_name` stores a compact or culturally recognized label, and
`raw_source_name` is audit-only.

## Verification

