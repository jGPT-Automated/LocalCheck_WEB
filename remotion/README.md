# LocalCheck Remotion hero

This workspace mirrors the landing-page scroll sequence as an editable Remotion composition.

```bash
cd remotion
npm install
npm run studio
```

Render the six-second 1920×1080 hero:

```bash
npm run render
```

The live website uses a lightweight scroll-scrubbed DOM version of the same sequence so navigation, text, and calls to action remain interactive. The Remotion composition is the source for rendered hero video experiments and timing iteration.
